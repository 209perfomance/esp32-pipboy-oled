# Схема подключения

## Компоненты

| Компонент | Кол-во | Примечание |
| :--- | :---: | :--- |
| ESP32 (WROOM-32 DevKit) | 1 | или ESP32-C3 Super Mini |
| OLED 0.96" 128×64 (SSD1306, I2C) | 1 | с 4 встроенными кнопками |
| Li-Po аккумулятор 3.7V | 1 | 300–500 mAh, размер ≤ 35×20×6 мм |
| Модуль зарядки TP4056 (Type-C) | 1 | с защитой, резистор R3 = 6.8 кОм |
| Кнопки тактовые | 4 | если не встроены в модуль экрана |
| Резисторы 100 кОм | 2 | для делителя измерения батареи (опционально) |
| Выключатель | 1 | между батареей и ESP32 |

## Подключение OLED + кнопок

Модуль экрана имеет 7 контактов: `GND, VCC, SCL, SDA, K1, K2, K3, K4`.

| Пин экрана | Пин ESP32 | Примечание |
| :--- | :--- | :--- |
| **GND** | GND | Земля |
| **VCC** | 3.3V | Питание (не 5V!) |
| **SCL** | GPIO 22 | I2C Clock |
| **SDA** | GPIO 21 | I2C Data |
| **K1** (верх, `^`) | GPIO 32 | Кнопка «вверх» |
| **K2** (вниз, `v`) | GPIO 33 | Кнопка «вниз» |
| **K3** (`#`) | GPIO 25 | Кнопка «ОК» |
| **K4** (`*`) | GPIO 26 | Кнопка «назад» / долгое = CLOCK |

> ⚠️ **Для ESP32-C3 Super Mini** распиновка другая: SDA = GPIO 8, SCL = GPIO 9, K1 = 3, K2 = 4, K3 = 5, K4 = 10. Меняется в `config.h`.

## Подключение питания (Li-Po + TP4056)
[USB Type-C] [TP4056]
│ │
│ ├── B+ ──── Красный провод батареи
│ ├── B- ──── Чёрный провод батареи
│ │
└── питание ─────────┤ OUT+ ──── 5V (ESP32)
│
└── OUT- ─── GND (ESP32)

text

### Схема соединений

1. **Батарея Li-Po** → **TP4056**:
   - `+` (красный) → `B+`
   - `−` (чёрный) → `B-`

2. **TP4056** → **ESP32**:
   - `OUT+` → `5V` (или `VIN`)
   - `OUT-` → `GND`

3. **USB Type-C на TP4056** — для зарядки батареи.

### ⚠️ Критически важно — ток зарядки

Стандартный TP4056 выдаёт **1 А**, что для батареи 350 mAh — смертельно много (ток в 3 раза выше ёмкости). **Замените резистор `R3`** на модуле:

| Номинал R3 | Ток зарядки | Подходит для батареи |
| :--- | :--- | :--- |
| 1.2 кОм (по умолчанию) | 1000 мА | ❌ опасно |
| 2.0 кОм | 580 мА | только для 600+ mAh |
| **5.0 кОм** | **250 мА** | ✅ оптимально |
| **6.8 кОм** | **176 мА** | ✅ безопасно |
| 10 кОм | 120 мА | ✅ медленно, но безопасно |

**Формула:** `I (мА) = 1200 / R (кОм)`.

Резистор нужен **SMD 0805** (или 0603). Если нет SMD под рукой — можно припаять выводной резистор на проводах (см. фото ниже в разделе «Кустарный вариант»).

## Измерение батареи (опционально)

Чтобы реально видеть процент заряда, нужен делитель напряжения:
Батарея + ────[ 100 кОм ]────┬──── GPIO 34 (ADC)
│
[ 100 кОм ]
│
GND

text

На GPIO 34 будет половина напряжения батареи:
- 4.2 V → 2.1 V (100%)
- 3.2 V → 1.6 V (0%)

В коде раскомментировать `#define PIN_BATTERY 34` в `config.h` и заменить `readBatteryPercent()` в `ui.h`.

## 3D-корпус

Модель корпуса в стиле Pip-Boy генерируется в **OpenSCAD**. Скрипт прилагается отдельно — см. `docs/CASE.md` (будет добавлено).

Корпус рассчитан на:
- Плата экрана: 44.6 × 27.5 × 4 мм (с кнопками)
- Батарея: 35 × 20 × 6 мм
- ESP32-C3 Super Mini: 25 × 20 мм
- TP4056: 26 × 17 мм

## Проверка подключения

После сборки — прошейте скетч и откройте **Serial Monitor** на скорости `115200`. Должно быть:
[I2C] Scanning bus... 0x3C
[OLED] OK
[BTN] OK. K1=32, K2=33, K3=25, K4=26
[WiFi] OK, IP=192.168.x.x
[Weather] OK
=== READY ===

text

Если I2C-сканер не находит `0x3C`:
- Проверьте питание (3.3V).
- Поменяйте местами SDA и SCL.
- Проверьте пайку пинов.

## Безопасность

- **Не подключайте Li-Po к ESP32 напрямую** — только через TP4056 или другой модуль зарядки.
- **Не подавайте 5V на VCC OLED** — сгорит.
- **Не заряжайте Li-Po без защиты** — используйте TP4056 с платой защиты или батарею со встроенным PCM.
- **Проверьте полярность** перед включением — красный = `+`, чёрный = `−`.
